## 已实现的链路

启动时构建一个可复用 ChatModel、Jev HTTP 客户端、Redis/SQLite/Chroma 服务、Skills 管理器和通用、技术、账单三个 LangChain Agent 图；人工升级由本地确定性交接节点处理。请求的身份、路由、工具轨迹和计量保存在独立运行上下文，不写到共享 Agent 对象上。

每轮 `/chat` 验证签名会话凭证并锁定会话，读取一次近期消息和摘要。父 workflow 执行一次 Jev + 本地规则路由，按主辅角色并行运行启动时构建的 Agent 图。中间件注入完整角色契约、角色输入包、命中 Skills、会话背景和工具白名单，并在工具执行时再次校验权限。每个技术/账单主辅分支失败后独立尝试一次通用回退，保留所有尝试及轨迹。Composer 以主处理结果为主，要求冲突结论需核验并注入通用 Skills；失败时后续答案加“补充说明：”。顶层 API 最后只保存一组用户/助手消息。

普通聊天不读取个人跨会话情景记忆、不更新用户画像。Redis 保存当前会话缓存，SQLite 同时保存可恢复的原始记录、处理轨迹、累计摘要及证据。没有另一套 checkpointer 重复保存消息。

## 结案与共享案例

结束状态 `open/closed` 与结果 `unknown/resolved/unresolved` 分开。`success=true`、用户表扬、超时或离开都不自动生成已解决案例。

用户凭会话凭证明确提交解决确认，或引用同一会话的用户原始消息。每个实际步骤必须由确认原文支持；环境也必须有用户记录依据。提取只保留通用问题、环境、有效步骤、结果、产品/版本/错误码和时间，原始身份与证据留在 SQLite。可选模型提取只接收已清理的候选内容；输出还需通过原文支持和质量校验。证据不足时关闭为 `unknown`，案例标记 `rejected`。

合格案例先保存 `pending`，再按稳定 case ID 幂等写入 `resolved_cases_v3`，成功才标记 `published`。写入失败保留待处理状态，可通过 retry 重试。撤销和重新打开首先取消 SQLite 中的检索资格；即使向量删除失败，检索结果仍会经 SQLite 生命周期复核，不再返回该案例。

检索在向量查询前使用 `$and` 组合业务 scope、published、active 以及非空产品/版本/错误码条件，之后检查相似度和实时发布状态。用户 B 可取得同范围的通用经验，无法取得用户 A 的账号、订单、联系方式或原始聊天。历史经验不能覆盖正式政策。

## 计量与使用限制

`/chat` 保留原响应字段。`intent_confidence` 为 Jev 对返回主意图的类别概率；没有有效 Jev 结果时为0。路由分数放在 `extra.routing_scores`，未校准的旧 `routing_confidence` 留0并在 `extra.routing_confidence_status` 说明，不将分数伪装成概率。 单分支路由的 `agent_type` 使用最终实际角色，例如技术失败后回退为 `general`；`primary_agent` 仍保留原选择。多分支的具体执行角色见 `extra.role_results`。新增 API 检查以真实 LangChain 图验证失败回退、返回字段兼容和会话仍只写入一组消息。

`llm_calls` / `input_tokens` / `output_tokens` 统计回答 workflow 内所有真实模型调用，包含 Agent、各自回退、知识查询改写/重排和主辅汇总；本地人工交接不产生生成模型用量。`extra.agent_results` 保存全部尝试，`extra.role_results` 保存各分支最终结果，失败尝试的模型/工具轨迹也保留。Jev 模型版本、请求次数、耗时和供应商 usage 在 `extra.jev`；记忆压缩用量在 `extra.memory_usage`；结案提取在关闭接口的 `extraction_usage`。这些口径分开，不能把 token 合计当成统一金额。工具轨迹保存调用 ID、参数、成功状态和耗时；`/metrics` 在请求结束后计数，避免将执行中请求视为失败。没有沿用旧监控的延迟降权规则。

本地会话创建使用 `X-Dev-Key`，随后使用带 owner、scope、conv_id 和过期时间的签名凭证。它是可信本地开发入口，完整生产登录、用户目录和授权系统尚未接入。追踪历史为有界进程内缓存，重启后不保留该 API 缓存；原始会话证据仍持久化。默认 SQLite/Chroma 目录归新项目所有，没有迁移或开放旧个人记忆数据。

本次完成的是可运行的 v3 项目与基本回归。尚未完成大规模质量/成本基准、生产身份接入、路由阈值校准和生产可靠性验收。独立 Docker Compose 配置已提供，尚未实际构建运行。
